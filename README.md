# AeroSound — Streamlit Frontend

AeroSound is a predictive maintenance project developed during the Le Wagon Data Science & AI bootcamp.

The application provides an interactive interface for acoustic anomaly detection in industrial machinery.

## Features

- **Presentation:** Five slides introducing the AeroSound project.
- **Live Demo:** Upload a WAV audio file, visualize its waveform, and request an anomaly prediction from the backend API.
- **API integration:** The frontend communicates with the deployed prediction service through an HTTP request.
